# Конвертер Excel в XML для ФГИС ТП

Конвертер читает лист «Заполнение» из шаблона НГП и проверяет XML по схеме `fgistp-ngp__11.xsd`. Приложение работает в современных браузерах с поддержкой WebAssembly и модульных Web Workers. Файлы, которые выбирает пользователь, обрабатываются в браузере.

## Публикация на GitHub Pages

1. Создайте репозиторий GitHub. Для GitHub Pages в бесплатном плане выберите **Public**.
2. Перенесите **содержимое распакованного архива** в корень репозитория. На одном уровне должны лежать `index.html`, `style.css`, `app.mjs`, `converter.mjs` и папка `assets`. В архив входит пустой Excel-шаблон. Рабочие таблицы и XML результатов храните отдельно от репозитория.
3. В репозитории откройте **Settings → Pages**. В поле **Source** выберите **Deploy from a branch**, затем ветку **main**, папку **/ (root)** и **Save**.
4. После публикации откройте URL из **Settings → Pages**. Обычно это `https://ИМЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

[Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Проверка после публикации

1. Скачайте шаблон со страницы. Скопируйте одну строку данных из листа «Примеры» в лист «Заполнение» начиная с пятой строки. Переносите только значения колонок A–L.
2. Загрузите файл в конвертер, нажмите **Подготовить XML** и скачайте результат после успешной проверки по XSD.
3. При наличии ошибок конвертер укажет номер строки Excel. Данные листа «Вне схемы» сохраняются в XLSX для сверки.

Для новых записей конвертер создаёт UUID. Чтобы при повторной выгрузке сохранить идентификатор той же записи, внесите её ранее выданный `GLOBALID` в таблицу. Единица измерения `MXDOS` сохраняется в комментарии XML. В самом поле хранится число, как задано в XSD.

## Локальный запуск

Откройте терминал в папке с `index.html`, выполните `python -m http.server 8000`, затем откройте [localhost:8000](http://localhost:8000/). Этот способ работает без GitHub.

## Компоненты

Чтение Excel выполняет SheetJS CE 0.20.3. Проверку XML выполняет xmllint-wasm 5.3.0 на базе libxml2. Все библиотеки и их лицензии находятся в `assets/vendor`.
